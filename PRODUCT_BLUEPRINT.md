### 10. SMART MATCHING ALGORITHM

#### Matching Factors

**Client Needs Analysis**
- Query text analysis (NLP)
- Category and subcategory
- Urgency level
- Budget range
- Language preference
- Location (if relevant)

**Advisor Scoring**
- Specialization match (weighted)
- Language capabilities
- Availability
- Response time (historical)
- Success rate
- Client ratings
- Pricing fit
- Workload balance

#### Algorithm Flow
1. Parse client query (extract entities, intent)
2. Generate advisor pool (filters)
3. Score each advisor (multi-factor)
4. Rank top 10 matches
5. Apply diversity (avoid single-advisor dominance)
6. Present to client OR auto-assign (urgent cases)

#### Learning Loop
- Track acceptance rates
- Monitor client satisfaction
- Adjust weights based on outcomes
- A/B testing of matching strategies

## 🗺️ USER JOURNEYS

### Journey A: Ask a Question (Private User)

1. **Landing & Discovery**
   - User arrives at homepage
   - Sees "Ask a Legal or Tax Question" CTA
   - Clicks → Signup/Login

2. **Question Posting**
   - Selects category (Legal or Tax)
   - Selects subcategory (e.g., "Employment Law")
   - Writes question in native language
   - Uploads supporting documents (optional)
   - Sets budget (€50-500 range)
   - Sets urgency (normal/urgent)
   - Clicks "Post Question"

3. **Matching**
   - Platform shows "Finding the best advisors..."
   - Auto-matching algorithm runs
   - 5-10 advisors notified

4. **Advisor Response**
   - Advisors view question
   - Submit answer proposals with quotes
   - Client receives notifications

5. **Selection**
   - Client reviews proposals
   - Compares advisor profiles, ratings, prices
   - Selects preferred advisor
   - Payment authorization

6. **Answer Delivery**
   - Advisor provides detailed answer
   - Client can ask follow-ups (included or paid)
   - Client marks as resolved

7. **Payment & Review**
   - Payment released to advisor
   - Client leaves rating and review
   - Advisor responds to review (optional)

---

### Journey B: Book Fixed Price Service (SME)

1. **Service Discovery**
   - User browses "Services" marketplace
   - Filters by category, price, delivery time
   - Views service detail page (e.g., "Business Formation Package")

2. **Customization**
   - Fills questionnaire (business type, location, etc.)
   - Selects add-ons (e.g., trademark search +€200)
   - Reviews total price and timeline

3. **Advisor Selection**
   - Sees advisors offering this service
   - Reviews profiles and portfolios
   - Selects advisor or lets platform auto-assign

4. **Booking**
   - Confirms booking
   - Pays deposit (30%)
   - Receives confirmation email

5. **Collaboration**
   - Advisor creates project workspace
   - Uploads initial documents
   - Client and advisor exchange messages
   - Video call scheduled (if needed)

6. **Milestone Completion**
   - Advisor delivers draft (Milestone 1)
   - Client reviews and requests revisions
   - Advisor submits final version
   - Client approves → Final payment released

7. **Completion**
   - All deliverables marked complete
   - Documents archived in workspace
   - Client leaves review
   - Advisor showcases in portfolio

---

### Journey C: Video Consultation (Freelancer)

1. **Scheduling**
   - User browns advisor profiles
   - Finds tax advisor with video consultation option
   - Clicks "Book Video Call"
   - Selects date/time from advisor's availability
   - Adds consultation notes/questions

2. **Payment**
   - Sees price (€150/hour or €80/30min)
   - Payment authorization hold
   - Confirmation email with calendar invite

3. **Preparation**
   - Both parties receive reminders (24h, 1h before)
   - Client uploads documents to shared workspace
   - Advisor reviews documents pre-call

4. **Video Call**
   - Client clicks "Join Call" in platform
   - HD video call starts
   - Advisor shares screen to review documents
   - Real-time translation subtitles (if needed)
   - Call is recorded (with consent)

5. **Post-Call**
   - AI generates call summary and action items
   - Transcript available in both languages
   - Follow-up tasks created in workspace
   - Payment charged for actual duration

6. **Follow-Up**
   - Client receives summary email
   - Can book follow-up call with discount
   - Can message advisor in chat for quick questions

---

### Journey D: Document Collaboration (Corporate)

1. **Project Setup**
   - Corporate client creates project: "M&A Due Diligence"
   - Invites team members (5 internal users)
   - Invites advisors (1 lawyer, 1 tax advisor)

2. **Document Upload**
   - Client uploads 50+ documents
   - AI automatically categorizes and extracts key info
   - Documents organized in folders

3. **Review & Annotation**
   - Lawyer reviews contracts
   - Highlights risks and adds comments
   - @mentions tax advisor for cross-over issues
   - Tax advisor reviews financial documents

4. **Video Meetings**
   - Weekly video calls with all parties
   - Screen sharing to review documents together
   - Whiteboard for diagramming entity structures
   - Recordings saved to project

5. **E-Signature Workflow**
   - Final agreements prepared
   - Sent for signature (multi-party)
   - Signing order: CFO → CEO → Counterparty
   - Notifications at each step
   - Completed docs auto-filed

6. **Project Closure**
   - All deliverables marked complete
   - Final invoices generated
   - Project archived (retained for 10 years)
   - Team receives project report
